▶ 실제 동작 영상

실제로 어떻게 동작하는지
직접 확인하세요

전체 스캔부터 순위 확인, 광고주센터 이동까지 실제 동작 영상

🎬 전체 스캔 실제 동작 영상
전체 스캔 시작 → 탭 자동 열림/닫힘 → 순위 결과 카드 실시간 표시 → Chrome 알림까지 실제 동작 화면
스캔 완료 시 Chrome 알림으로 미달/미노출 항목을 즉시 통보. 결과 카드는 초과달성·달성·미달·미노출 색상으로 구분됩니다.
📋 키워드 관리 카드
네이버 검색 결과에서 내 광고에 컬러 테두리 + 📍 배지로 순위를 직접 표시. 1위는 초록, 미달은 빨간 테두리.
🏢 광고주 계정 관리
담당자별로 그룹 정리. 에이전트 관리 엑셀 Ctrl+A → 붙여넣기로 대량 등록.
📋 키워드 관리 카드
지면별(PC·모바일) 체크박스, 광고주 드롭다운 연결, 목표순위 설정을 카드 하나에서 관리.
✅ 안전성

네이버 이용약관
완전 준수

크롤러가 아닙니다. 브라우저가 탭을 여는 것은 사용자가 직접 검색하는 것과 완전히 동일합니다.

🖥️
브라우저 탭 방식
Chrome이 일반 탭을 열어 사용자가 검색한 것과 동일하게 동작합니다. 서버에 직접 HTTP 요청을 보내는 크롤러와는 기술적으로 전혀 다릅니다.
🔒
사용자 클릭 기반
자동 반복, 스케줄링 기능이 없습니다. 사용자가 버튼을 누를 때만 동작하며 과도한 서버 부하를 주지 않습니다.
💾
100% 로컬 저장
모든 데이터는 Chrome 로컬 스토리지에만 저장됩니다. 외부 서버로 데이터를 전송하지 않습니다.
📋
네이버 약관 준수
네이버 이용약관이 금지하는 "자동화된 수단으로 서버에 과도한 부하를 주는 행위"에 해당하지 않습니다.

📦 설치 방법

3분이면 설치 완료

별도 회원가입, 서버 연결 없이 Chrome에 바로 설치

1
ZIP 다운로드 후 압축 해제
아래 다운로드 버튼 클릭 → plrank-unified.zip 을 원하는 폴더에 압축 해제
2
chrome://extensions 열기
Chrome 주소창에 chrome://extensions 입력 → 우측 상단 개발자 모드 토글 ON
3
폴더 로드
"압축해제된 확장 프로그램 로드" 클릭 → plrank-unified 폴더 선택
4
관리계정 ID 입력 후 시작
툴바 아이콘 클릭 → 사이드패널 열림 → 소속 관리계정 ID 입력 → 완료!
